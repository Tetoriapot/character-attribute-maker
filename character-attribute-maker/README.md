# キャラ属性メーカー

キャラクター画像を自由な二軸マップへ配置し、PNG画像として保存できるブラウザツールです。

上・下・左・右の属性名を自由に設定できるため、「善／悪 × 混沌／秩序」や「生／死 × 生物／概念」など、創作・TRPG・キャラクター整理のさまざまな分類図を作れます。

## 起動方法

ビルドやインストールは不要です。

1. `index.html` をダブルクリックします。
2. Chrome、Edge、Firefox、Safariなどのブラウザで開きます。

ローカルWebサーバーを利用できる場合は、このフォルダーを任意の静的サーバーで配信しても動作します。

GitHub Pagesで公開する場合は、リポジトリルートの `.github/workflows/pages.yml` が `main` ブランチへの更新時にこのフォルダーを自動公開します。初回だけ、GitHubのリポジトリ設定で **Settings → Pages → Source → GitHub Actions** を選択してください。

## 主な機能

- 図のタイトルを自由に設定し、編集画面とPNGへ表示
- 上下左右の軸ラベルを自由に編集
- タイトルと評価語を図の内側／外側へ切り替え
- 外側レイアウトの左右ラベルを縦書き／横書きから選択
- PNG・JPEG・WebP画像を複数アップロード
- ファイル選択、ドラッグ＆ドロップの両方に対応
- サムネイルのクリック、またはマップへのドラッグで画像を配置
- アップロード画像を複数選択、または一括で削除
- Pointer Eventsによるマウス・タッチでのドラッグ移動
- 属性マップを25～200％で拡大・縮小し、ウィンドウへ自動フィット
- ヘッダーのHelpと更新情報から、操作方法と変更履歴を確認
- 編集パネルとマップ周辺の余白を抑えたコンパクト表示
- キャンバス外へ画像が完全に出ないように位置を制限
- 選択画像の前面移動、削除、複製、サイズ変更
- キャラクター名、枠色、枠の太さ、四角形／円形、名前表示の設定
- 選択中の画像サイズ、枠色、枠の太さ、形状、名前表示を配置中の全画像へ一括適用
- 図の内側と外側で背景を独立設定し、それぞれ単色、2色グラデーション、アップロード画像、透過に対応
- 内側背景の不透明度を0～100％で調整（軸、文字、キャラクターには影響しません）
- 軸線も単色、または選択した2色のグラデーションに対応
- 軸線（矢印）の長さ、矢印先端サイズ、線幅、不透明度を調整
- 日本語向け10種類のフォントと文字色を選択
- 内側背景プリセットの変更
- Undo／Redoとキーボードショートカット
- 800×800、1600×1600、2400×2400のPNG出力
- PC中心のレスポンシブ表示とタッチ操作
- タイトル、軸ラベル、色、軸長、フォント設定を同じブラウザのLocalStorageへ保存

背景グラデーションは左上から右下へ変化します。軸線グラデーションは、横軸が左から右、縦軸が上から下へ変化し、矢印の先端にも両端の色が反映されます。

背景画像は中央を基準に正方形へ切り抜いて表示します。透過背景を選んだ場合、編集画面の市松模様は透明部分を示すための目印で、PNGには含まれません。

外側背景は「図の外側」レイアウトで、タイトルと評価語が置かれる余白を含む出力全体へ表示します。内側背景はキャラクターを配置するマップ部分へ表示します。内側背景を半透明にすると外側背景が透けて見え、軸線・文字・キャラクター画像は不透明のまま保たれます。

「タイトル・評価語の配置」で「図の外側」を選ぶと、正方形の出力領域内に余白を設け、タイトルと上下左右の評価語をマップ枠の外へ配置します。配置済みキャラクターのマップ内での位置は切り替えても変わりません。左右の評価語は縦書きと横書きを選べます。外側の余白に収まらない長い言葉は末尾を省略して表示し、編集画面ではマウスポインターを重ねると全文を確認できます。

### アップロード画像を削除する

画像一覧の「選択して削除」を押すと、サムネイルを複数選択できます。「すべて選択」で全件を選び、「選択を削除」で選んだ画像をまとめて削除できます。「すべて削除」は画像一覧を一度に空にします。

画像一覧から削除すると、その画像を使っているマップ上の配置もすべて同時に削除されます。確認画面に削除される画像数と配置数が表示され、実行後も「元に戻す」でサムネイル、位置、名前、サイズ、重なり順を復元できます。背景画像、軸、タイトル、色設定は削除されません。

### 配置画像の見た目を一括変更する

基準にしたい画像をマップ上で選び、画像サイズ、枠色、枠の太さ、切り抜き形状、名前表示を設定してから「この見た目を全画像に適用」を押します。選択中の5項目だけが、マップ上に配置済みの全画像へ反映されます。

キャラクター名、基本の配置位置、重なり順は維持します。サイズ変更や名前表示によって端からはみ出す画像だけは、キャンバス内へ収まるよう位置を自動調整します。一括適用は1回の操作として記録されるため、「元に戻す」と「やり直す」で全画像をまとめて復元できます。

### 属性マップの表示倍率

マップ上部の「−」「＋」ボタン、またはスライダーで表示倍率を25～200％の範囲で変更できます。「100%」を押すと原寸表示に戻り、「ウィンドウに合わせる」を押すと、現在の編集領域の横幅と高さの両方に収まる倍率へ自動調整します。

初期状態はウィンドウに合わせた表示です。この状態ではウィンドウサイズの変更にも追従します。手動で倍率を変更すると固定倍率へ切り替わり、再び「ウィンドウに合わせる」を押すまで倍率を維持します。拡大して表示領域を超えた部分は、表示領域内のスクロールで確認できます。

表示倍率は編集画面だけの設定です。キャラクターの位置・サイズ、Undo／Redo、PNGの出力解像度や内容には影響しません。

### Helpと更新情報

ヘッダーの「？」を押すと、マップ作成の基本手順、画像操作、キーボード操作、PNG保存時の注意を確認できます。「更新情報」では、機能追加や画面改善の履歴を日付順に表示します。

新しい更新がある場合は「NEW」を表示します。更新情報を開いて閉じると既読になり、同じブラウザでは次の更新までバッジを表示しません。既読状態だけをLocalStorageへ保存し、画像や配置内容は保存しません。

### キーボード操作

| 操作 | キー |
| --- | --- |
| 選択画像を削除 | `Delete` または `Backspace` |
| 選択画像を少し移動 | 矢印キー |
| 選択画像を大きく移動 | `Shift` ＋ 矢印キー |
| 元に戻す | `Ctrl` / `Command` ＋ `Z` |
| やり直す | `Ctrl` / `Command` ＋ `Shift` ＋ `Z`、または `Ctrl` / `Command` ＋ `Y` |
| 選択解除／画像の削除選択を終了 | `Escape` |

入力欄を編集中は、Delete、Backspace、矢印キーなどを編集操作として横取りしません。

## PNG出力方法

1. 図のタイトル、軸ラベル、内側／外側レイアウト、内側・外側背景、軸線、フォントを設定します。
2. 画像を追加してマップへ配置します。
3. 必要に応じてキャラクター名、サイズ、枠、形状を調整します。
4. 「すべての背景を含めて保存」と出力サイズを選びます。チェックを外すと内側・外側の両背景が透過します。
5. 「PNG画像を保存」を押します。

保存ファイル名は `character-attribute-map.png` です。PNGには図のタイトル、選択中の内側・外側背景、軸、軸ラベル、配置画像、表示中のキャラクター名だけが含まれます。外側レイアウトを選んだ場合は、余白とマップ枠を含む正方形の構成で出力します。背景画像、背景と軸線のグラデーション、内側背景の不透明度、軸長、矢印先端サイズ、線幅、軸の不透明度、フォントも画面設定に合わせて出力されます。編集画面の表示倍率には左右されません。設定パネル、市松模様、選択枠、リサイズハンドルなどの編集用UIは含まれません。

## プライバシーと保存

- アップロード画像や入力内容を外部サーバーへ送信しません。
- 画像はブラウザ内でData URLとして一時的に処理します。
- キャラクター画像、背景画像、配置内容はLocalStorageへ保存しません。ページを閉じる前にPNGで保存してください。
- 図のタイトル、軸ラベル、内側／外側レイアウト、左右ラベルの向き、内側・外側の背景モードと色、内側背景の不透明度、軸線・文字の色、軸長、フォント設定は同じブラウザに保存され、再読み込み時に復元されます。
- 更新情報の既読状態を同じブラウザに保存します。「すべて初期化」では既読状態を変更しません。
- 内側・外側の背景画像を設定した状態で再読み込みした場合は、画像を保存しないため各背景が単色へ戻ります。
- 「すべて初期化」を実行すると、画像、背景、配置、名前、ラベル、フォント、色設定を初期状態へ戻します。

## ファイル構成

```text
character-attribute-maker/
├─ index.html  # 画面構造
├─ style.css   # デザインとレスポンシブ表示
├─ script.js   # 状態管理、画像操作、PNG出力
└─ README.md   # このファイル
```

外部ライブラリ、フレームワーク、画像素材、ビルド環境は使用していません。

リポジトリ全体の公開方法とGitHub Pagesの設定手順は、ひとつ上の階層にある `README.md` に記載しています。

## 対応ブラウザ

以下のモダンブラウザの現行版を想定しています。

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

Pointer Events、Canvas API、FileReader、ResizeObserver、LocalStorage、Data URL、`canvas.toBlob()`を利用します。古いブラウザやInternet Explorerには対応していません。
