# TIER ATELIER

PCとスマートフォンでTier表を作成する、ブラウザ内で動作するWebアプリです。フェーズ6のPWA・オフライン対応まで実装しています。

公開先は[GitHub PagesのTIER ATELIER](https://tetoriapot.github.io/character-attribute-maker/tier-atelier/)です。開発環境の保存データを移す場合は、画像込みJSONを保存して公開先で復元してください。

## 現在使える機能

Tierの追加・削除・複製・改名・背景色と文字色の変更・並べ替え・ロック・折りたたみに対応しています。文字アイテムを作成し、名前・説明・タグを編集できます。アイテムはドラッグ、移動先の選択、前後ボタンで配置できます。

PCでは3カラムと左右パネルの表示切替、スマートフォンでは下部ツールバーと設定ドロワーを使用します。日本語UI、キーボード操作、ダイアログのフォーカス管理、エラー表示に対応しています。

画像の一括登録、画像を共有するアイテム複製、プロジェクトの作成・一覧・切り替え・複製・削除にも対応しています。確定した編集内容と画像は、このブラウザのIndexedDBへ自動保存します。再読み込みすると、前回開いていたプロジェクトを読み込みます。

画像を含むJSONバックアップと復元ができます。背景・文字・カードのデザイン編集とテンプレート、PNG・JPEG・WebP出力、印刷・共有、Undo・Redo、検索・タグフィルター、複数選択・一括移動に対応しています。オフライン編集と更新通知も利用できます。実機検証の残件は[TASKS.md](TASKS.md)に記録しています。

## 起動

Node.js 22.12以上の偶数メジャー版とpnpmを使用します。開発時の検証環境はNode.js 24.19.0、pnpm 11.25.0です。

```powershell
cd C:\Projects\相関図ツール\tier-atelier
pnpm install --frozen-lockfile
pnpm dev
```

ターミナルに表示されるローカルURLを開いてください。ファイルを直接ダブルクリックして起動する構成ではありません。

## 基本操作

1. 「画像を追加」でファイルを複数選択するか、「文字を追加」で名前を入力して「追加する」を押します。新しいアイテムは未分類に入ります。
2. アイテムを選び、「移動先」を選択して「移動する」を押します。ドラッグハンドルからも移動できます。
3. ランク名を選ぶと設定が開きます。名前と色を入力し、「変更を適用」を押します。色はカラーピッカーとカラーコードのどちらでも指定できます。
4. ランクやアイテムの順序は上下・前後ボタンで変えます。ドラッグでも並べ替えられます。

スマートフォンではタップして設定ドロワーを開きます。ドラッグハンドルを約300ミリ秒長押しするとドラッグを開始できます。スクロールはハンドル以外の場所から操作してください。

キーボードではTabで対象を選び、Enterで実行します。ドラッグハンドルではSpaceで開始し、矢印キーで移動、Spaceで確定、Escapeでキャンセルします。移動先の選択と上下ボタンもキーボードで操作できます。ダイアログはEscapeまたは「閉じる」で閉じます。

ランクを削除すると、そのランクのアイテムを順序どおり未分類の末尾へ移します。ランクの複製では名前・配色・設定をコピーし、アイテムは複製しません。ロックしたランクは改名・配色変更・直接の並べ替え・削除と、所属アイテムの編集・移動を制限します。別のランクの追加や並べ替えによって表示位置がずれることはあります。

入力欄の変更は「変更を適用」で確定します。未適用の入力がある状態で別のランクやアイテムを選ぶときと、プロジェクトを切り替える前に、入力を破棄するか確認します。追加フォームや設定ドロワーを閉じると未適用の入力は破棄します。右上の「Help」にも主要操作を記載しています。

## 右上の操作

「更新情報」で使用中のバージョンと変更内容を確認できます。アプリの更新確認・適用は、既存の「アプリ・オフライン」から行います。

表示モードボタンでライトとダークを切り替えます。初回は端末の配色設定を使い、切り替え後はこのブラウザに保存します。同じサイトを開いている別タブにも反映します。Tier表のデザイン、出力画像、JSON、Undo・Redoの履歴には影響しません。保存が失敗した場合は、その旨を画面に表示して今回の切り替えを維持します。

「Help」にはTierとアイテムの編集、キーボードとタッチ操作、検索・一括操作、保存・出力・オフラインの説明があります。更新情報とHelpはEscapeまたは「閉じる」で閉じ、開いたボタンへフォーカスを戻します。

## Undo・Redoと検索・一括操作

「元に戻す」「やり直す」で、確定済みの編集を最大100操作まで戻せます。Tier・アイテムの編集や配置、デザイン・テンプレート、画像登録・背景変更・切り抜きも対象です。画像の一括登録と一括移動はそれぞれ1操作です。Undo後に新しい編集を確定すると、Redoの履歴は消えます。

Ctrl／⌘＋ZでUndo、Ctrl／⌘＋Shift＋ZまたはCtrl＋YでRedoを実行します。入力欄では文字入力の履歴を操作します。未適用の入力がある場合は破棄を確認し、ドラッグ中やダイアログ表示中にはショートカットで編集履歴を変更しません。

履歴は再読み込み・プロジェクト切り替えで消えます。プロジェクト自体の作成・複製・削除・復元はUndoの対象に含めません。削除した画像は、履歴から戻せる間だけメモリにも保持します。

「検索・選択・表示設定」を開くと、名前・説明・タグを検索できます。空白で区切った語と、選択したタグをすべて含む項目を表示します。英字の大小、全角・半角を正規化して比較します。検索で隠れた項目のデータと配置は保持します。

「複数選択」でチェックを表示し、「表示中を選択」で検索に一致する項目をまとめて選べます。Ctrl／⌘＋クリックで追加・解除、Shift＋クリックで直前に選んだ項目から範囲選択できます。「一括移動先」を選んで「選択項目を移動」を押すか、選択した項目のハンドルをドラッグします。

選択項目は表の表示順で移動します。ランクは上から、各ランク内は左から並べ、その後に未分類の選択項目を続けます。移動先では末尾に追加し、項目へのドロップではその位置へ挿入します。

検索で非表示になった選択項目も一括移動の対象です。画面に非表示の選択数を表示します。ロック中のランク内は新たに選択できず、選択後にロックした項目が含まれる場合も移動全体を中止します。

表示倍率は50〜200%、グリッドは20px間隔です。拡大時は表の領域を横スクロールできます。検索・選択・倍率・グリッドは編集画面だけの設定で、JSONや出力画像には反映しません。

未分類の表示対象が100件以上になると、見えている範囲とその前後だけを描画します。項目のボタンにフォーカスを移し、矢印キー、Home／End、PageUp／PageDownで移動できます。画面外へスクロールしても、フォーカス中・ドラッグ中の項目を保持します。スクリーンリーダー向けに項目の位置と総数を付けています。

## 画像の登録

PNG・JPEG・WebP・GIFに対応しています。ファイル選択、画面へのファイルのドロップ、画像の貼り付けが使えます。入力欄への通常の貼り付けは、文字入力として扱います。GIFは最初のフレームを静止画として表示し、元ファイルも保持します。

上限は1枚20MiB、一辺8,192px、32メガピクセルです。1回の登録は100枚・合計100MiBまで、1プロジェクトの元画像は合計128MiBまでです。MiBは1,048,576バイトです。拡張子・MIME・実データを照合し、画像としてデコードできることも確認します。複数画像の中に不正なファイルがあれば、そのファイル名と理由を表示し、正常な画像だけ登録します。

表示用サムネイルは縦横比を保ち、長辺160px以内で作成します。アイテムを複製しても元画像は複製しません。最後の参照を削除した画像は、ほかのプロジェクトからも参照されていなければ保存先から削除します。

## 保存・プロジェクト・バックアップ

画面上部に「保存中…」「保存済み」「保存できませんでした」を表示します。保存が失敗した場合も編集内容は画面に残し、再試行とJSONバックアップを案内します。保存していない変更、未適用の入力、処理中の操作がある場合は離脱時に確認します。OSやモバイルブラウザによる終了時には確認を表示できない場合があります。

「プロジェクト一覧」から作成・切り替え・複製・削除を行います。切り替える前に現在の編集を保存します。最後のプロジェクトを削除すると、空の新しいTier表を作成します。別タブで同じプロジェクトが変更された場合は、上書きせず保存を停止します。その場合は現在の編集をバックアップしてから再読み込みしてください。

「JSONバックアップ」は、現在の確定済みの編集と元画像を1つの`.tier.json`ファイルへ保存します。保存失敗中でも実行できます。「JSONから復元」でそのファイルを選ぶと、内容を検証して新しいプロジェクトとして保存します。既存プロジェクトは上書きしません。JSONファイルの上限は256MiBです。

保存先はブラウザ・プロファイル・サイトのオリジンごとに異なります。開発用とpreview用のポートが異なる場合も保存先は別です。ブラウザのデータ削除やプライベートブラウズの終了で保存内容が消えることがあるため、必要なプロジェクトはJSONバックアップを保存してください。

## デザイン編集

PCでは左側、スマートフォンでは下部バーの「デザイン」を開きます。背景を単色・グラデーション・パターン・画像から選び、文字、見出し、ラベル幅、画像サイズ、余白、角丸、枠、影を設定できます。「デザインを保存」で適用すると、自動保存が始まります。ランクごとの最小高さとラベル幅は、ランク設定から変更します。

テンプレートはクラシック・ミニマル・ゲームUI・レトロ・ポップ・サイバー・ゴシック・和風の8種類です。「全体」「ランクのみ」「画像カードのみ」から適用範囲を選び、「テーマを適用」を押します。ランク配色は別に3種類あります。Tier名・ID・並び順・アイテム・配置は保持し、ロック中のTierの色は変えません。配色数よりTierが多い場合は、上から順に色を繰り返します。

「背景画像を登録」は選択後すぐに適用・保存します。画像登録と同じ形式・寸法・容量制限を使い、プロジェクトの画像合計128MiBに含めます。テーマ適用などで背景の種類を切り替えても、登録済みの背景画像は保持します。「画像」に戻すと再表示でき、「背景画像を削除」で参照を解除できます。

画像アイテムの設定では、左端・上端・幅・高さを元画像に対する割合で入力してトリミングできます。元画像は変更せず、切り抜き範囲を保存します。JPEGはEXIFの向きを反映し、GIFの画像カードは最初のフレームを表示します。背景画像には元ファイルを表示するため、アニメーションGIFは再生されます。

デザイン設定、背景画像、トリミングはプロジェクト複製とJSONバックアップにも含まれます。フェーズ2のJSONも読み込めます。フォントは端末にある書体を使用するため、端末によって見た目が異なります。狭い画面ではラベル幅・画像サイズ・余白を表示幅に合わせて縮め、保存値は維持します。

## 画像出力・印刷・共有

画面上部の「出力・共有」を開き、形式・基準幅・倍率・出力内容を選んで「プレビューを作成」を押します。作成した画像は「画像を保存」から保存できます。設定を変えた場合は、プレビューを作り直してください。

基準幅は320〜2,400px、倍率は1・2・3倍とカスタム0.1〜4倍です。表の高さは内容に合わせて伸びます。出力は一辺8,192px・合計1,600万画素以内とし、超えた場合は倍率か基準幅を下げる案内を表示します。長いアイテム名やランク名は折り返して出力します。端末のメモリ不足などで失敗した場合も編集データを保持します。

PNG・WebPでは透過背景を選べます。透過時は表全体の背景色・画像・パターン・グラデーションを除き、ランクとカードの色は残します。JPEGは背景を描画します。タイトル・説明と未分類を含めるかは別々に選択でき、未分類は初期状態では含めません。出力にボタン・選択枠・ドラッグハンドルは入りません。折りたたんだTierも出力します。

出力には確定済みのデザインと元画像を使い、切り抜き範囲・EXIFの向き・縦横比を反映します。GIFは背景を含め最初のフレームを使用します。フォントを読み込んでから描画しますが、端末にない書体は代替書体になります。画像形式に対応していないブラウザでは、PNGへの変更を案内します。成功した出力の設定は同じブラウザ内で保持します。

「印刷ページを作成」でA4縦・余白12mmのページに分割し、「印刷する」でブラウザの印刷画面を開きます。通常はカードの行やTierの区切りで改ページし、1ページより高い内容は途中で分割します。画像の欠落や重複がないように全体を連続して分割し、透明部分は白く印刷します。印刷画面でヘッダー・フッターをオフにしてください。PDF保存も印刷先から選択できます。

「画像を共有」は作成済みの画像を、「共有用JSONを作成」→「プロジェクトを共有」は画像を含むバックアップを、端末の共有機能へ渡します。ファイル共有に対応していない環境ではファイルをダウンロードします。共有用JSONは通常の「JSONから復元」で開けます。

「共有URLを作成」は画像のないプロジェクト向けです。プロジェクトの文字・設定をURLの`#tier=`以降に含め、全体を8,000文字以内に制限します。削除していない背景画像や非表示の素材が残る場合もJSONを使ってください。URLの内容は暗号化されず、受け取った人が閲覧できます。取り込み前に検証し、利用者が取り込みボタンを押した場合だけ新規プロジェクトとして保存します。

## 検証とビルド

### PWA・オフライン・更新

本番ビルドをHTTPSまたはlocalhostで開き、「アプリ・オフライン」で「オフラインで利用できます。」と表示されるまで待ちます。準備後は同じURLをオフラインで開き、保存済みプロジェクトの編集、画像登録、デザイン、画像出力、JSONバックアップと復元、Undo・Redoを利用できます。共有先への送信には接続が必要な場合があります。

対応ブラウザではインストールボタンを表示します。iPhone・iPadではSafariの共有メニューから「ホーム画面に追加」を選べます。[Appleの案内](https://support.apple.com/ja-jp/guide/iphone/iph42ab2f3a7/ios)も参照してください。インストールはオフライン利用の必須条件ではありません。

更新が見つかると通知を表示します。「あとで」で通知を閉じても、同じ設定画面から更新できます。「保存して更新」は確定済みの変更を保存してから再読み込みします。未適用の入力、画像登録などの処理、ドラッグが残る場合は更新できません。同じ公開先を別タブ・ウィンドウで開いている場合は、その編集を保存して閉じてから再試行します。

保存や更新の取得に失敗した場合は現在の画面を保持し、エラーを表示します。保存失敗時はJSONバックアップを確保してから再試行してください。更新後は、通常の再読み込みと同じくUndo・Redo履歴と検索・選択状態がリセットされます。更新確認は起動時、オンラインへの復帰時、画面への復帰時と「更新を確認する」から行います。自動確認の間隔は最低60秒です。

ブラウザのデータ削除や容量不足によって、保存データやオフライン用ファイルが失われる場合があります。必要なプロジェクトは画像込みJSONを保存してください。開発サーバーではService Workerを登録しません。

### コマンド

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm exec playwright install chromium
pnpm test:e2e --workers=2
pnpm test:pwa
pnpm build
pnpm preview
```

Playwright用Chromiumがインストール済みなら、ブラウザのインストールは不要です。通常のブラウザテストはポート4178でViteを起動します。PWAテストは`.qa/`内に2版の本番ビルドを作り、ポート4180で静的配信を切り替えます。テストはユーザーのブラウザプロファイルや既存データを使用しません。

`pnpm build`で生成される`dist/`を静的サーバーで配信できます。`base: './'`を指定しているため、サブディレクトリへの配置に対応します。[公開手順](docs/deployment.md)にGitHub Pages・さくらサーバーの配置、更新、復旧方法を記載しています。既存のキャラ属性メーカー用公開ワークフローは変更していません。

## データと拡張

プロジェクト、Tier、アイテムにはUUIDを使用します。Tierの順序は`tiers`、アイテムの順序は各Tierの`itemIds`と`unrankedItemIds`で管理します。配置変更は一括更新し、同じアイテムが複数箇所に所属しないようにしています。

画像素材は`blobKey`で参照し、元画像とサムネイルのBlobをプロジェクトとは別のテーブルに保存します。日本語文言は`src/app/`内の`messages.ts`、`storageMessages.ts`、`designMessages.ts`、`exportMessages.ts`、`editingMessages.ts`、`pwaMessages.ts`にまとめています。保存形式の詳細は[DATA_SCHEMA.md](DATA_SCHEMA.md)、設計方針は[docs/development-plan.md](docs/development-plan.md)を参照してください。

テーマは`src/data/themes/themes.json`、ランク配色は同じディレクトリの`ranks.json`で管理します。配列に固有の`id`、表示名、配色、必要なスタイルを追加すると選択肢に反映されます。テーマの省略項目は`features/design/settings.ts`の既定値を使い、読み込み時にZodで検証します。

```text
tier-atelier/
├─ public/                 ローカルの静的ファイル
├─ src/
│  ├─ app/                 画面全体・文言・エラー境界
│  ├─ components/          Tier表・サイドバー・フォーム・ダイアログ
│  ├─ data/                型・初期値・Zod検証・マイグレーション・Dexie
│  ├─ features/editor/     編集コマンド・差分履歴・検索・ドラッグ・仮想表示
│  ├─ features/design/     デザイン既定値・テーマ検証・表示用スタイル
│  ├─ features/assets/     画像検証とサムネイル生成
│  ├─ features/backup/     画像を含むJSON入出力
│  ├─ features/export/     Canvas画像出力・印刷・共有URLとファイル
│  ├─ features/storage/    自動保存とプロジェクト操作
│  ├─ features/pwa/        更新・インストール・保存前確認
│  ├─ features/appearance/ 表示モードとブラウザへの設定保存
│  ├─ stores/              Zustand状態管理
│  └─ styles/              共通スタイルとレスポンシブ表示
├─ tests/unit/             編集・保存・検証・入出力の単体テスト
├─ tests/e2e/              Playwrightブラウザテスト
├─ tests/pwa/              本番ビルドのオフライン・更新テスト

├─ DATA_SCHEMA.md
├─ TEST_CASES.md
```
