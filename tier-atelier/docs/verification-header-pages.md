# ヘッダー機能・GitHub Pages検証記録

2026年10月28日にv0.7.0を検証しました。実行環境はWindows、Node.js 24.19.0、pnpm 11.25.0、Playwright Chromiumです。

## 検証結果

GitHub ActionsのUbuntu環境で、型チェック・lint・単体79件・ブラウザ101件・PWA16件・本番ビルドが成功しました。端末条件に応じたスキップはブラウザ7件・PWA2件です。

Windowsでも型チェック・lint・単体・ビルドとブラウザ回帰を実施しました。閉じる操作の修正後に画像生成テスト1件が5秒の待機上限に達したため、既存の出力テストと同じ15秒にそろえています。最後の変更に対してヘッダー関連12件とPWA16件が成功し、その後のGitHub Actionsで全体の成功を確認しました。

右上の更新情報・表示モード切替・Helpを、320・390・768・1,280・1,920pxで確認しました。ライトとダークで画面とダイアログを開き、横方向のはみ出し、Tab、Escape、フォーカス復帰を確認しました。axeでWCAG 2 A／AA・2.1 AAに該当する違反は検出されませんでした。

表示モードは端末設定を初期値とし、切り替え後の再読込・別タブへの反映を確認しました。不明な保存値とLocalStorageの保存失敗でも編集画面が動作します。切り替え前後でJSONのプロジェクトと画像、出力PNG、Tier表の表示スタイルが一致し、Undo・Redoの操作数も変わりません。

既存機能は、画像24枚の登録と再読込、プロジェクト作成・複製・削除、画像込みJSON往復、デザインとテンプレート、PNG・JPEG・WebP・透過・倍率、印刷・共有、検索・複数選択・移動、仮想トレイ、Undo・Redoを確認しました。PWAではオフライン編集、更新通知、保存失敗・未適用入力・別タブの保護、ブラウザ再起動後の保存内容を確認しました。

## 公開と確認方法

既存のGitHub Pagesワークフローで、キャラ属性メーカーをルート、TIER ATELIERを`tier-atelier/`へ配置します。型チェック・lint・単体・ブラウザ・PWAテストとビルドが成功してから配信します。

コミット`2121367`を[GitHub Actionsの実行40544912844](https://github.com/Tetoriapot/character-attribute-maker/actions/runs/40544912844)で公開しました。

[公開ページ](https://tetoriapot.github.io/character-attribute-maker/tier-atelier/)はHTTPSで正常に応答しました。ManifestとService Workerのスコープが`/character-attribute-maker/tier-atelier/`内に収まることを確認しました。PCとスマートフォン条件で、更新情報・Help・表示モードの保存、画面のはみ出し、axeの検査を実施し、違反とコンソールエラーは0件でした。

公開ページで画像24枚を登録し、Tier移動とサイバーテンプレートを保存しました。JSONから別プロジェクトへ復元し、元画像のバイト列とデザインを確認しています。オフラインで再読込し、PNG・JPEG・WebP出力、画像の追加、Undo・Redo、再保存・再読込を確認しました。表示モード変更前後とJSON復元前後でPNGが一致し、最後は25枚の画像を表示できました。

既存のキャラ属性メーカーは引き続きルートで表示され、HTMLがGitに保存された既存版と一致しました。作業前からあった`character-attribute-maker/index.html`の未コミット変更は保持し、今回の公開には含めていません。

初回のGitHub Actionsではブラウザ98件が成功し、複数ページを作る印刷テスト1件が5秒の待機上限に達しました。印刷ボタンが有効になることを待つ上限を15秒へ変更しました。ページ数、全画像の読み込み、出力内容、改ページで画素を失わないことの検証は維持しています。失敗時のブラウザ診断ファイルはActionsの成果物として7日間保存します。

次の実行では背景画像の登録中に閉じる操作が無視され、設定画面が残るケースを確認しました。処理中の「閉じる」を無効にして、完了後に操作できるよう修正しています。画像の読み込みを意図的に保留し、ボタン・Escape・完了後のJSON出力を確認するテストを追加しました。プロジェクト操作中とPWA更新中のダイアログにも同じ制御を適用しています。
