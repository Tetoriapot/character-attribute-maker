# 画像登録と画像名の一括非表示

2026年10月28日にv0.7.1を検証しました。環境はWindows、Node.js 24.19.0、pnpm 11.25.0、Playwright Chromiumです。

## 原因と修正

提示された2枚は拡張子が`.png`で、実データは240×240pxのJPEGでした。v0.7.0で両方とも形式の不一致エラーになることを再現しました。登録時に実データの形式を判定し、対応する画像形式間の拡張子・MIMEの不一致を補正するよう修正しました。元のバイト列とファイル名は保持します。容量・寸法・実画像のデコード検証、未対応形式の拒否、JSON復元時の整合性検査は維持しています。

「検索・選択・表示設定」とデザインの「カード・枠」に「画像名を一括で非表示」を追加しました。画像の名前だけを隠し、文字アイテムの設定と名前のデータは保持します。今後追加する画像と出力にも適用します。設定は自動保存・JSON復元・Undo／Redoの対象で、テンプレートを変更しても維持します。旧データと既存の「アイテム名を表示」の動作は変えません。

## 検証結果

添付2枚をPCとスマートフォン条件で登録し、240×240pxのJPEGとして保存できることを確認しました。JSON内の元画像が添付ファイルとバイト単位で一致し、名前を隠した状態の保存・再読み込み・PNG出力が成功しました。コンソールエラーはありませんでした。実ファイルとスクリーンショットはローカルの除外ディレクトリに置き、リポジトリと公開物には含めません。

型チェック・lint・単体85件・ブラウザ108件・PWA16件・本番ビルドが成功しました。端末条件によるスキップはブラウザ8件・PWA2件です。PCとスマートフォン条件で実画像のJSON復元とオフライン再読込も成功しました。

ブラウザテストでは、非表示の画像名を変更してもPNG・JPEG・WebPがバイト単位で一致することを確認しました。文字アイテムの表示、120画像の仮想トレイ、キーボード・タップ、Undo／Redo、追加画像、未適用入力のキャンセル、デザイン設定との同期、axeの検査も成功しました。画像登録・プロジェクト管理・デザイン・出力・印刷・共有・保存・JSON・履歴・PWA更新の既存テストをすべて実行しています。

初回の追加テストでは、スマートフォンでJSON復元後に閉じている「検索・選択・表示設定」を開く操作が抜けていました。テストの操作手順を修正し、その後の全ブラウザテストが成功しました。

ビルド時の既存チャンクサイズ警告とPWAプラグイン内部の非推奨オプション警告は残っています。
