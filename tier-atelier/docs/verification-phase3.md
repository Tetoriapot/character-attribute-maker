# フェーズ3の検証記録

実施日：2026年10月27日。Windows、Node.js 24.19.0、pnpm 11.25.0、Playwright Chromiumで確認しました。

## 実装

背景色・背景画像・グラデーション・パターン、フォント・文字色・見出し、画像サイズ・表示方法・トリミング、ラベル幅・Tierの高さ・余白・角丸・枠・影を追加しました。デザインはPCのプロパティパネルとスマートフォンのドロワーから編集します。

8種類のテーマと3種類のランク配色をJSONで定義しました。適用範囲を全体・ランク・カードから選択し、既存のTier名・ID・アイテム・配置を維持します。背景画像は既存のBlob保存処理へ接続し、切り抜き範囲はアイテムの任意フィールドとして保存します。既存JSONキーとschemaVersion 1は維持しています。

## 新機能と回帰の確認

デザイン値とTier個別寸法を編集し、保存後の再読込で値と表示を確認しました。画像24枚と背景画像1枚、切り抜き範囲、Tier内の配置をJSONへ保存し、新しいプロジェクトへ復元しました。元画像のバイト列・配置・設定が往復前後で一致しています。

切り抜きはCanvasの画素も確認し、指定範囲外の色が余白に出ないことを検証しました。EXIFで90度回転するJPEGでも、表示方向に沿った範囲を切り抜き、元ファイルを保持しています。背景画像の置換・削除では、複製プロジェクトから参照されているBlobを残すことを単体テストで確認しました。

既存のTier作成・編集・削除・複製・ロック・折りたたみ、文字アイテム編集、ドラッグと代替移動、画像一括登録、プロジェクト管理、自動保存、JSON復元を回帰確認しました。保存容量不足・別タブ競合・IndexedDB開始失敗・不正ファイルのテストも通過しています。

表示幅320・768・1280・1920pxで、デザインの最大値を設定しても意図しない横スクロールがないことを確認しました。PC・スマホの設定画面、暗色テーマ、最大サイズ、切り抜き画像はスクリーンショットでも確認しました。

## 検証中の修正

下部ツールバーが2段になってバックアップボタンを覆う問題を、CSSの読み込み順の修正で解消しました。暗色テーマでは編集ボタンに専用の文字色を指定し、コントラストを確保しました。

切り抜き画像の余白へ元画像の一部が表示される問題は、切り抜く範囲をCanvasで指定する描画に変更して修正しました。テーマやランク配色を適用するときは、破棄を承認した未適用の入力も設定欄から取り除きます。

## 制限と残件

スマートフォンの確認はChromiumのiPhone 13エミュレーションです。実機のiPhone・Androidと支援技術による読み上げは、後続フェーズで確認します。フォントは端末の書体を使用し、任意の利用者指定色や背景画像についてコントラストを自動補正する機能はありません。

production buildには500kB超のチャンク警告が残っています。フェーズ2からの警告で、今回のJSは599.08kBです。型・ビルド・操作上の失敗はありませんが、公開前に読み込み負荷と分割方法を検討します。

画像出力はフェーズ4、Undo・Redoはフェーズ5、PWA・オフライン対応はフェーズ6の要件です。今回の実装では公開処理を行っていません。
