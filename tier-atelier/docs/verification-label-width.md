# ランク名の列幅の検証

検証日：2026年10月28日。Node.js 24.19.0、pnpm 11.25.0、Windows上のChromiumを使用しました。

## 変更内容

ランク設定と「デザイン」→「サイズ・余白」に、自動／手動の切り替えを追加しました。自動では現在のフォント・文字サイズで各ランク名を測り、最も広いものに全行の列幅を合わせます。改名、ランクの追加・削除、フォント変更時にも再計算します。

手動の共通幅と個別幅は48〜600pxです。自動表示中も指定値を保持し、手動に戻すと再び使います。自動／手動の指定がない旧JSONは従来の手動表示として読み込みます。自動／手動の選択はテンプレート適用後も保持します。

画面と画像出力は同じ自動幅の計算を使います。狭い表示・出力では表の40%までに収め、文字を折り返します。画像出力に操作ボタンは入りません。

## 検証内容

単体テストでは、同じ文字数でも幅が異なる文字、改行、ロックアイコン、長文、ランク削除、手動への復帰、不正値の拒否、旧データ・未知キーの保持を検証しました。編集履歴の既存テストには、ランク名と共通幅を同時に変更する操作を追加しています。

ブラウザでは「とても儚い」のPC表示を1行に収め、全行の幅がそろうことを確認しました。共通・個別幅、個別幅の解除、Undo／Redo、保存・再読込・JSON往復、キーボード、axeも検証対象です。PNG・JPEG・WebPは生成画像の画素から列の境界を調べ、フォント・文字サイズを反映した自動幅との一致を確認しました。

320・390・768・1024・1920pxで横方向にはみ出さず、列幅の上限内で折り返すことを確認しました。PC・スマートフォン条件の設定画面、Tier表、PNG出力を画像でも確認しました。スマートフォンはChromiumのiPhone 13エミュレーションで、物理端末は未検証です。
