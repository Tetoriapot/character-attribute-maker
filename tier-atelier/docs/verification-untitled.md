# タイトルなしの保存・出力

検証日：2026年10月29日。Node.js 24.19.0、pnpm 11.25.0、Windows上のChromiumを使用しています。

## 変更内容

プロジェクト名を空欄にして保存・出力できるようにしました。前後の空白を除き、半角・全角の空白だけなら空文字列として保存します。120文字の上限とJSONキーの必須条件は維持しています。

タイトルなしでは出力の見出し用余白・下線・帯を省き、説明文は出力設定に従って保持します。一覧・ヘッダー・共有データの取り込み画面には「タイトルなし」と表示し、画像やJSONにはこの表示名を代入しません。空のタイトルは複製しても空のままです。

## 確認内容

単体テストでは空欄・半角空白・全角空白、タイトルの型・上限・必須キー、配置と説明の保持、共有URL、出力レイアウトを確認しました。Undo／Redoの既存テストにもタイトル削除を追加しています。

PC・スマートフォン条件でタイトルを削除し、Undo／Redo、再読込、画像込みJSON復元、PNG・JPEG・WebPの保存を確認しました。タイトルと説明が空のときは、タイトルの出力設定をオン・オフしても生成画像のバイト列が一致します。説明だけがあるときも、見出し装飾を切り替えて画像が変わらないことを確認しました。

タイトルなしでの新規作成・複製・一覧表示・印刷ページ、axe、画面と生成画像も確認しました。スマートフォンはChromiumのiPhone 13エミュレーションで、実機は未検証です。

## 結果

型チェック・lint・単体91件・ブラウザ116件・PWA16件・本番ビルドが成功しました。端末条件によるスキップはブラウザ8件・PWA2件です。

本番ビルドのPC・スマートフォン条件でも、空白だけのタイトルの保存・JSON復元・オフライン再読込・PNG出力を確認しました。空の5段のTier表は960×544pxで出力され、タイトル用の余白と編集UIは入りません。コンソールエラーは0件です。

画像登録、デザイン編集、ランク名の自動・手動幅、プロジェクト管理、自動保存、画像込みJSON、Undo／Redo、PNG・JPEG・WebP出力、検索・選択、PWA更新とオフライン編集の既存テストも成功しています。公開先での確認結果は公開後に追記します。
