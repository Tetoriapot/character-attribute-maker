# フェーズ4の検証記録

実施日：2026年10月27〜28日。Windows、Node.js 24.19.0、pnpm 11.25.0、Playwright 1.64.1で確認しました。

## 実装

PNG・JPEG・WebP出力、基準幅、1・2・3倍とカスタム倍率、透過、タイトル・説明と未分類の出力設定を追加しました。確定したプロジェクトと元画像からCanvasへ描画し、編集DOMは取り込みません。日本語の折り返し、元画像の切り抜き、フォント準備待ち、出力サイズ上限、未対応形式の案内に対応しています。

A4向けの分割印刷、画像・画像込みJSONのファイル共有、画像を含まない小さなプロジェクトのURL共有も追加しました。URL取り込みは検証後に新規プロジェクトとして保存します。保存形式の既存キーとバージョンは維持しています。

## 出力ファイルと印刷

PNG・JPEG・WebPを実際にダウンロードし、拡張子だけでなくファイルヘッダー、デコード後の幅・高さ、背景画素のアルファ値を確認しました。1・2・3倍とカスタム1.5倍、日本語と空白を含むファイル名、設定の再読込が成功しています。

21枚の元画像を含む表を出力し、指定した切り抜き色とcontainの余白を画素で確認しました。Tierを折りたたみ、選択枠や検査用ボタンを編集画面に追加しても、出力PNGのバイト列は一致しました。タイトル・説明と未分類を含めると、出力内容と高さに反映されます。

全8テーマの出力を保存し、背景・日本語・文字カードを目視確認しました。24枚の画像、背景画像参照、切り抜き、文字・サイズ・余白・枠・影・Tier個別寸法を設定した表では、再読込とJSON復元の前後で出力PNGが一致しました。元画像のバイト列も保持しています。

20Tierの表から2ページのA4印刷データを作成しました。ページにボタンや入力欄がなく、分割前後の総画素高が一致することを確認しました。同じ画像と印刷スタイルを使ってChromiumでPDFを生成し、Popplerで両ページを画像化して、改ページ・余白・日本語・内容の連続性を目視確認しました。ブラウザの印刷呼び出しは差し替えて検証し、紙への印刷は行っていません。

出力パネルは320・390・768・1280・1920pxで意図しない横スクロールがないことを確認しました。空表、長い名前、寸法上限、未対応形式、フォント準備待ちも検証しています。

## 共有と既存機能

端末の共有APIへ渡すFileの名前・MIME、共有キャンセル、未対応時のダウンロードを確認しました。共有APIは差し替え、外部の相手へファイルを送っていません。共有用JSONを既存の復元操作で開き、画像を再表示できました。

共有URLではUnicode・配置・設定・未知キーを保持し、不正な形式・バージョン・参照、画像を含むデータ、上限超過を拒否しました。URLからの取り込みで既存プロジェクトが残り、新規プロジェクトが追加されることを確認しました。HTMLに見える文字も文字列として表示します。

Tierとアイテムの作成・編集・削除・複製、ロック、折りたたみ、ドラッグ・代替移動、画像一括登録、プロジェクト管理、デザイン編集、テンプレート、自動保存、画像込みJSONの往復を回帰確認しました。保存容量不足、別タブ競合、IndexedDB開始失敗、不正画像・不正JSONのテストも成功しています。

## 検証中の修正

長いプレビューへキーボードフォーカスを移してスクロールできるようにしました。長いランク名の行高を描画時の行間と一致させ、狭い領域の文字が隣へはみ出さないよう描画幅を制限しました。

最初の画素テストはカードの枠内を画像として判定していたため、画像内の座標へ修正しました。形式切り替えの検証では、並列実行中の画像生成が5秒を超える場合があったため、完了状態を最大15秒待つようにしています。

## 制限と残件

Firefoxの検証用バイナリは`spawn UNKNOWN`で起動できず、今回の動作確認はできていません。Windows版WebKitでは、独立したIndexedDBへBlobを書き込むだけでも`UnknownError: Error preparing Blob/File data to be stored in object store`が発生しました。同じテストで文字列とArrayBufferは保存できました。WebKitの描画・出力は確認しましたが、画像の永続化を確認済みとはしていません。Safari実機での保存・出力確認は公開前に必要です。

iPhone・Android実機、スクリーンリーダー、OS固有の共有先選択、実際のプリンターへの印刷は未確認です。フォントの見た目は端末の書体によって変わります。

主JSが500kBを超えるビルド警告は残っています。出力パネルを別チャンクにしましたが、既存の主JSを含む読み込み負荷は公開前に確認します。Undo・Redoなどはフェーズ5、PWA・オフライン対応はフェーズ6の要件です。公開処理は行っていません。
