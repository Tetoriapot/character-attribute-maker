# アイテムの一括ドラッグ削除

検証日：2026年10月29日。Windows、Node.js 24.19.0、pnpm 11.25.0、PlaywrightのChromiumを使用しています。

## 変更内容

複数選択したアイテムを、ドラッグ中に表示される削除エリアへ落として一括削除できます。タッチではハンドルを長押しします。ボタンから確認画面を開く方法も用意し、キーボードで操作できます。選択していないアイテムをドラッグすると、その1件だけを扱います。

検索で非表示になった選択項目も対象に含め、削除エリアに件数を表示します。仮想スクロールで画面外にある選択も対象です。Escapeでの中止や削除エリア外へのドロップでは削除しません。ランクのドラッグでは削除エリアを表示しません。

削除を1つの編集コマンドにまとめ、全IDとロックを検査してから変更します。画像を参照するほかのアイテムや背景を保持し、既存の履歴と自動保存を使ってUndo／Redoできます。未適用の入力を破棄する確認でキャンセルした場合も、削除を中止します。保存形式と依存ライブラリは変更していません。

ダークモードの仮想トレイで、操作説明と件数のコントラスト不足も修正しました。
